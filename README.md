# Data

- `delivery_logistics_raw.csv` — simulated raw shipment-level logistics data
  (500 records) with intentionally injected missing values, duplicates,
  outliers, and inconsistent categorical entries. Generated by
  `src/generate_dataset.py`.
- `delivery_logistics_cleaned.csv` — analysis-ready output of the Week 2
  cleaning pipeline (`src/data_preprocessing.py`): no missing values, no
  duplicates, outliers capped, plus Min-Max/Z-score scaled columns and a
  few engineered features (`cost_per_km`, `order_day_of_week`, `is_delayed`).
